# CreatorDock 本地可用版 · 2026-09-26

## 打开应用

解压交付 ZIP 后，在 macOS 双击根目录的 `启动CreatorDock.command`，会在本机启动网页应用并打开浏览器。需要 Python 3.9+；交付包自带 `dist/`，无需安装 npm 依赖。保持终端窗口开启，按 Ctrl+C 停止。

也可以在项目目录运行：

```sh
python3 scripts/serve-built.py
```

固定地址：`http://127.0.0.1:5187/CreatorDock/`。请持续使用同一个地址和浏览器；本地草稿、入口和加密密钥按浏览器站点分别保存。已有开发目录的数据不会自动迁移到这个地址。

首次使用，打开“模型设置”，填写自己的接口、型号、API Key 和本机加密口令，保存后测试连接。个人写作风格是可选项。付费模型请求由用户点击生成或测试连接时直接发往所配置的服务商。

## 本次交付内容

- 以 GitHub 和用户 ZIP 共同对应的 `2670ecb` 为基础，复用另一份本地仓库已有的五个内容包提交（至 `1faca3d`），在独立工作区继续完善。
- 同一选题可适配多个已有平台入口。账号改成自定义昵称后仍保留真实平台信息。
- 最近 20 组内容包可切换回看、复用选题、直接编辑，自动保存在当前浏览器；可导出 Markdown 成稿。
- 某个平台失败不影响其他稿件；重试只请求未完成稿件，保留成功和人工编辑的内容。
- 单篇和内容包均可停止请求；刷新后未完成的内容显示中断，可继续处理。
- 写作请求有 120 秒上限，结束时释放流读取器和取消监听。
- 修复流式最后一段丢失、服务商错误事件被当成功、空结果显示成功的问题。
- 本地内容包存储写入失败时仍保留页面上的内容，并明确提醒立即导出。
- 手机顶部提供“平台入口 / 开始创作”导航；桌面写作区加宽；输入区域位于历史结果之前。
- 修正 GPT Image 返回格式参数；GPT Image 1 系列仅显示 1:1、2:3、3:2 尺寸，避免默认发送无效尺寸。依据 [OpenAI 官方 SDK 的 Images 定义](https://github.com/openai/openai-node/blob/master/src/resources/images.ts)。

## 验证

本次未修改既有测试断言、未删除或跳过原有测试。新增回归先复现失败，再验证修复。

- 单元 / 组件：140 项通过，覆盖加密、配置、流式解析、内容包恢复、存储失败等。
- TypeScript：`tsc -b --pretty false` 通过。
- 生产构建及 PWA 产物检查通过。
- Chromium：12 项通过，包含生成、部分失败重试、编辑、导出、历史恢复、停止、手机导航、入口管理和离线加载。
- 模型和封面测试使用模拟服务商响应；没有使用用户密钥，没有产生付费 API 调用。

开发环境的对应命令（正常安装 Node/npm 后）：

```sh
npm ci
npm test
npm run typecheck
npm run test:e2e
```

`npm run test:e2e` 会构建应用、检查产物、启动临时服务、运行 Chromium 并关闭自身服务。首次需安装 Playwright Chromium：`npx playwright install chromium`。

## 交付边界

这是已验证的本地网页 / PWA 版本，不是已签名的 macOS 或 Windows 安装包。本机没有 Rust 工具链，未运行 Tauri 原生构建；Windows PowerShell / 快捷方式测试也未在此 Mac 上执行。原有 Tauri 与 Windows helper 源码保留。

真实模型可用性、账户额度及浏览器跨域策略需要用用户自己的服务商配置验证。封面仅支持已有 OpenAI Images 兼容格式；参考图编辑、厂商专用适配器仍未实现，界面会明确说明，不会假装生成成功。

此版本集中管理发布入口和成稿，不会代替用户登录平台或自动发布内容。没有推送 GitHub、部署网站或创建公开 Release。
